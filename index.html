What to check before shipping

  1. Confirm the variant and fit. Save the size and color shown on the current listing. For shoes, compare stated insole length with a pair that fits. For clothing, compare flat chest width and body length with a garment you own.
  2. Review warehouse QC photos if available. Match the tag and color to your order. Check both shoes and their soles, or inspect garment seams and closures. Ask for a ruler photo if a measurement affects your decision.
  3. Check the delivered cost. Add item price, domestic shipping, agent fees and international freight. Check applicable duties and taxes separately, and use the same destination and package dimensions when comparing quotes.
  4. Check the return deadline. Confirm when the return window starts, who pays return postage and whether the agent can return the item while it is still at the warehouse.

OopBuy spreadsheet questions

What is an OopBuy spreadsheet?

It is a product directory used to compare listings before ordering through a shopping agent. This independent guide sources its product cards from CAFANS and lets you export the visible listings as a CSV.

How do I check whether a product works with OopBuy?

Open the CAFANS product detail and check the available agent options. If you use the original seller link, confirm that OopBuy accepts it and shows the same size and color before paying.

Where can I find QC photos?

Use the agent’s warehouse order view if your order includes inspection photos. The images in this directory come from the product listings. For fit checks, ask the agent whether they can provide a measurement photo.

Which weight should I use for a shipping quote?

Ask the agent whether the route charges by actual weight, dimensional weight or the higher of the two. Compare quotes using the final packed dimensions and the same destination postal code.
